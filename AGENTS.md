# Agent instructions

This repository is a set of Agent Skills. If your agent does not load skills on its own:

- To make a narrated animated video from code, read `skills/animated-story/SKILL.md` and follow it.
- To write or fix a story or voice-over script only, read `skills/story-script/SKILL.md`.

Paths inside a skill are relative to that skill's folder. Run its scripts through their interpreter
(`python3 …`, `node …`).
